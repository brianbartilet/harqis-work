Processing and optional export

Historical enrichment runs in bounded background batches. Explicit references are available even before extraction finishes.

  1. Enrich corpus history queues extraction of people, organizations (including companies, nonprofits and public institutions), tools and topics from activity evidence. It needs the configured background worker; queued or pending means processing has not finished. Saved profiles are preserved.
  2. Check progress shows the job state and last batch counts. Once processing finishes, use Refresh entities to load the updated directory.
  3. Export Obsidian vault writes activity notes, daily indexes and entity links to the server’s configured vault folder. It is a one-way export, not a browser download or a backup of edited profiles. Set HARQIS_OBSIDIAN_VAULT on the server first. Locally edited notes are reported as conflicts instead of overwritten; review the export result in Technical details.
