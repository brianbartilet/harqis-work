Connect an MCP client

Replace the example paths with absolute paths on the machine running your MCP client. Use that checkout’s virtual environment. The server loads the host’s existing environment and app configuration.

{{ mcp_examples.mac }}

Choose apps and check discovery

Optionally set MCP_ENABLED_APPS in the client’s env, for example jira,knowledge. An empty value attempts to register all apps. Missing configuration can cause an app to be skipped.

Reconnect the client after changing its configuration, then use its tool discovery to check what loaded. A stopped daemon is normal for this stdio server.

For a remote host, use a client-supported SSH stdio launcher with paths on that host. The Swagger URL is not an MCP URL.

Inspect tools from a terminal

Run these discovery commands from the HARQIS checkout with its virtual environment active. They list tools and input schemas; they do not call the selected tool.

python -m tools apps
python -m tools commands jira
python -m tools schema jira get_jira_issue

The CLI and MCP use the same app registry. CLI writes require --confirm-write; that CLI flag is not an MCP permission setting. Tool access in MCP depends on your client and host configuration.
