Connector brand assets

These shared assets use light marks on transparent backgrounds for the dark
Integrations cards and Fleet connector avatars. Paths and proportions are
preserved; solid foreground colors are adapted to slate-200 where needed.

- GitHub: white Invertocat SVG from https://brand.github.com/GitHub_Logos.zip (https://brand.github.com/foundations/logo). Existing white mark retained.
- Jira: SVG from @atlaskit/logo 23.3.1, https://unpkg.com/@atlaskit/logo@23.3.1/dist/esm/artifacts/logo-components/jira/icon.js (https://atlassian.design/components/logo/usage). Tile omitted; foreground set to slate-200.
- n8n: SVG from https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/n8n.svg (https://dashboardicons.com/icons/n8n). Foreground set to slate-200.
- Nod: official favicon from https://nod.n8n.io/docs/favicon.svg. Background tile omitted; ring and dot set to slate-200. The older nod.png and nod.source.txt are retained as the original source record.
- Codex: transparent monochrome logomark from https://asvg.app/assets/svg/codex/codex-symbol-monochrome.svg (https://asvg.app/icons/codex), distributed from the community-maintained @lobehub/icons-static-svg package. currentColor resolved to slate-200 for standalone image use.
- Grok Bot: monochrome logomark from https://asvg.app/assets/svg/grok-bot/grok-bot-logomark-mono.svg (https://asvg.app/icons/grok-bot). Existing slate-200 foreground and eye mask retained.

Brand marks remain the property of their respective owners and identify these
integrations; adapted theme treatments do not imply endorsement.
